# 同人作品識別碼服務：產品規格草案

狀態：規劃中，尚未實作。更新日期：2026-11-17。

## 目標與識別層級

服務讓同人作品的每個**發行版本**取得可公開查詢、可印在實體商品上的自有代碼。漫畫、圖集、文字、影片、音訊、遊戲及混合作品都能登錄；代碼不是 ISBN、GTIN，也不代表著作權認證。

- **主作品**：固定的作品紀錄，保存原始標題、創作者與介紹，串起不同發行版本。原始內容檔不會因此被永久保存。
- **發行版本**：第一版、第二版、不同語言、內容修訂或不同媒介各自登錄。相同內容的重印可沿用代碼；同一作品在不同主要市場推出獨立發行版時可分碼。
- **發行者**：創作者、社團或獲授權的發行方。顯示名稱可更改；發行者代碼一經分配即保持不變。

首版以登錄、發碼、預覽圖片、外部連結及公開查詢為主；不實作原檔上傳或內容比對。

## 帳號、驗證與發碼

1. 使用者以帳號、密碼、Email 註冊，或使用 Google／X 登入。註冊完成即可使用一般帳號功能。
2. **開始建立作品登錄前**，帳號須完成 Email 驗證，並在自己控制的網站首頁加入指定 `<meta>` 標籤，通過網站驗證。社群帳號登入仍須有可驗證的 Email。沒有可控制 HTML 的網站，不能建立作品登錄。
3. 登錄者建立主作品與發行版本，填寫發行者、主要首發市場、作品類型、發行媒介、語言、版本、分級等資料，並聲明其創作者或授權者身分。
4. 必要資料與驗證通過後自動發碼，基本書目立即公開。網站驗證只證明網站控制權，不能單獨證明作品權利；爭議由管理員處理。
5. 定期複查網站標籤。驗證失效時保留既有代碼、在公開頁標示狀態，並暫停新申請；重新驗證後恢復。

## 代碼格式

格式：`{發行國}-{發行者}-{作品類型}-{發行媒介}-{單件識別}-{檢查碼}`。示意碼：`JP-8K2M7-CM-BK-03F8A4-K`。

| 段落 | 長度 | 意義 |
| --- | ---: | --- |
| 發行國 | 2 | 該發行版的主要首發市場；不是作者國籍或作品語言。 |
| 發行者 | 5 | 系統分配的穩定英數代碼，對應登錄的發行主體。 |
| 作品類型 | 2 | 創作內容的分類，例如 `CM` 漫畫、`VD` 影片。 |
| 發行媒介 | 2 | 交付／販售載體，例如 `BK` 書籍、`BD` Blu-ray。 |
| 單件識別 | 6 | 系統產生的英數識別，在同一發行者下不得重複使用。 |
| 檢查碼 | 1 | 偵測輸入錯誤；暫定忽略連字號後以 Luhn mod 36 計算。 |

各段核發後不可改寫。若發行國、發行者、作品類型或媒介填錯，應保留舊碼的更正紀錄並核發新碼，避免已印出的代碼改變意義。語言、價格、全部販售地與作品分級是獨立欄位，不編進代碼。

發行者代碼空間須預留部分代碼供特殊用途，正式發碼流程不得分配給發行者。保留代碼的具體字面值、用途及查詢行為留待實作時定義；用於測試或展示時，不得使其被誤認為正式核發的代碼。

查詢 API 未實作；未來可依完整代碼、發行國、發行者、作品類型、發行媒介查詢。這些段落應各自保存為可索引欄位，避免查詢完全依賴代碼字串的前綴比對。代碼用於人可讀的識別與檢查，主作品及版本關係仍由資料紀錄維護。

## 首版圖片與連結

- 登錄者可自行上傳作品預覽圖片，選擇要展示的內容；**不因漫畫、影片、遊戲等作品類型而要求不同圖片**，也不從作品原檔自動擷取。可上傳多張圖片，並指定一張作為列表與公開頁的主圖。
- 預覽圖片可在發碼時或發碼後補上，不是發碼條件。發碼後可編輯作品介紹與購買頁、官方網站等外部連結。
- 成人向作品保留基本書目供查詢；預覽圖片依分級與地區展示設定處理。圖片由登錄者提供，不表示平台已驗證圖片與作品原檔一致。
- 首版不代管試閱本、試玩版、試看片段等其他檔案；可先放其外部介紹或購買連結，檔案代管留待後續評估。

公開頁顯示代碼各段的解讀、發行者網站驗證狀態、主作品與其他版本關係，並提供指向公開頁的 QR，方便印在實體商品上。介面規劃繁中、英文、日文；作品標題與介紹保留原文，翻譯選填。

## 原檔上傳與內容比對：保留規劃，首版不實作

原先構想允許登錄者暫時上傳完整作品原檔，計算 SHA-256 與依媒體類型而異的內容特徵，處理後刪除原檔。這是**後續候選功能**，首版不提供上傳入口、暫存、解析工作、雜湊或特徵欄位，也不以內容相似度阻擋發碼。先前 mockup 的「原檔處理」畫面只代表這項後續構想，首版畫面應改為預覽圖片管理。

先前討論的候選流程保留如下，不表示首版承諾實作：

- 一個發行版本可暫傳多個原檔，合計上限暫定 20 GB；上傳及特徵計算採非同步流程。
- 每檔串流計算 SHA-256。漫畫解析頁面、影片解析影格與音訊、遊戲比對封裝結構及可解析素材；未知格式只有通用檔案特徵，並標示比對能力。遊戲或可執行檔不在工作環境執行。
- 跨帳號出現完全相同原檔時暫停發碼交由人工審查；近似特徵僅作提示，不自動判定侵權。
- 成功處理後立即刪除原檔；失敗重試期暫定最長 72 小時，逾期清除。須設隔離解析、解壓與資源上限、刪除證據及演算法版本紀錄。

SHA-256 只辨識完全相同的位元組；轉檔、裁切或重新封裝後的近似比對，需要各媒體專用方法，不能把「特徵值」宣稱為唯一值。

### 作品類型

作品類型回答「作品本身是什麼」，不由上傳的預覽圖或發行媒介推定。複合內容由登錄者選主類型；確實無法歸入單一類型時選 `MX`。

| 代碼 | 類型 | 例子 |
| --- | --- | --- |
| `CM` | 漫畫 | 紙本漫畫、電子漫畫 |
| `AR` | 圖集／畫集 | 插畫集、設定畫集 |
| `TX` | 文字 | 小說、評論集 |
| `VD` | 影片 | 動畫、短片、實拍影片 |
| `AU` | 音訊 | 音樂、廣播劇、聲音作品 |
| `GM` | 遊戲 | 電腦、主機或手機遊戲 |
| `MX` | 複合媒體 | 無法指定單一主類型的作品 |
| `OT` | 其他 | 目前分類未涵蓋的創作 |

### 發行媒介

發行媒介回答「這個版本如何交付」，與作品類型獨立。例如漫畫可為 `CM-BK` 或 `CM-DL`，遊戲可為 `GM-BD` 或 `GM-DL`。同一作品換媒介發行時取得另一個版本代碼。

| 代碼 | 媒介 | 說明 |
| --- | --- | --- |
| `BK` | 書籍 | 裝訂成冊的紙本書 |
| `LT` | 小冊子 | 薄冊、折頁等小型印刷品 |
| `DV` | DVD | DVD 光碟；代碼使用 `DV`，顯示名稱為 DVD |
| `BD` | Blu-ray | Blu-ray 光碟 |
| `CD` | CD | 音訊或資料光碟 |
| `CT` | 卡匣／記憶卡 | 實體遊戲或資料載體 |
| `DL` | 數位下載 | 電子書、影片、音檔、遊戲安裝檔等 |
| `ST` | 線上存取 | 串流或瀏覽器內使用，無獨立下載版 |
| `BX` | 套裝／盒裝 | 同一發行品項含多種實體內容 |
| `OT` | 其他媒介 | 目前列表未涵蓋的交付方式 |

作品類型與媒介代碼在核發後不得改義或回收；需要新增分類時加新碼，既有作品保留原碼。
