直播電視牆 Mockup/data/vtubers/wall・暫不放入口・假資料
看點
  1. 格數依可用空間決定，最少 5×5、最多 9×9：YouTube 要求播放器至少 200×200 px，16:9 的格子以「寬 356、高 200」為單位算出能放幾格，再夾在 5～9 之間。實測（頁首扣掉後）：1080p 是 5×5、1440p 是 6×6、4K 是 9×9。目前格數顯示在右上角。
  2. 1080p 的 5×5 在網站框架內每格高度不到 200 px（約 190）；按右上「全螢幕」拿掉網站 header 與頁首後約 214 px，符合規定。
  3. 依開台時間排列（最早開播的在左上），每分鐘重抓。新開播的接在後面、已結束的移除，其他格不重排。直播比格數多時只顯示前面的，右上角標出「顯示 25／30」。格子比直播多時，空格留黑。
  4. 全部預設靜音，每一路右上角的喇叭各自切換，可以同時開好幾路。有聲音的格子外框會亮起來、喇叭一直顯示。
  5. 點一路就全螢幕（實作用 Fullscreen API 原地放大，不搬動 iframe，不會斷流），右上角可切聲音、關閉回到電視牆；Esc 也能退出。其他格照常靜音播放，由常數 KEEP_OTHERS_PLAYING_ON_FOCUS = true 決定，之後效能不夠再改成 false 暫停。
  6. 手機（UA 判斷）不顯示電視牆，改顯示「不支援手機」的提示與回直播行事曆的按鈕；不會載入任何播放器。
  7. 不能嵌入的直播（會員限定、關閉嵌入）播放器會回錯誤，實作時從牆上移除、後面的往前補。
  8. 影片從哪來：網址不帶任何 ID，頁面自己抓 /lives?status=live、每分鐘重抓。電視牆本身做成只吃「影片清單」的元件，資料來源另外接，之後要做「使用者自選多部存檔一起播」時，加一個來源（例如 /data/vtubers/wall?v=ID1,ID2,…）就能共用同一面牆。
