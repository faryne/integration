藝人頁導覽＋短片 Dialog Mockup往下捲看分頁移到左欄
看點
  1. 黏在上方（建議）：桌機跟手機一樣，分頁列捲到 header 下方就黏住，從分頁列切換時捲回內容頂端。
  2. 移到左欄：往下捲到分頁列離開畫面後，左欄的個人檔案收合成「頭像＋名稱＋訂閱按鈕」，下面出現直式分頁（即將直播／所有影片／行事曆／統計）＋「回到頂端」。左欄整欄黏在 header 下方，所以捲到多下面都點得到。往回捲到分頁列出現時，左欄恢復完整的個人檔案。
  3. 個人檔案要收合，是因為完整版大約 560px 高，筆電螢幕扣掉 header 後塞不下「完整檔案＋分頁」。
  4. 點左欄的分頁：切換內容並捲回內容頂端（不是整頁頂端）。
  5. 手機：只有一欄，兩種模式都是分頁列黏在 header 下方（切到 Mobile 往下捲看看）。
  6. 導覽方式：控制列可以切換「黏在上方」（建議：桌機手機同一種做法、版面不會跳）與「移到左欄」比較。
  7. 影片 dialog（components/common/YouTubeDialog）加上說明：打開時才去抓（每部 1 unit，Redis 快取），預設收合 3 行，網址可以點。資訊區太長時只捲這一塊，按鈕固定在最下面。
  8. 短片：同一個元件傳入直式參數。桌機左邊 9:16 播放器、右邊資訊欄（說明預設展開，太長只捲右欄）；手機寬度不夠並排，改回上下排、說明收合、整個 dialog 可以捲。用控制列「開一般影片／開短片」比較，手機版要先切到 Mobile 再開。
