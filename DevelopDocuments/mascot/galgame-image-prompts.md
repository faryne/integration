# galgame.tv 看板娘繪圖提示稿

搭配 [正式設定稿](galgame-mascot.md) 與現有圖稿重製時使用。角色為 155 cm 的成年女性；三張圖的臉、髮色、單側高馬尾、水藍髮尾、珊瑚粉眼睛與銀色海豚髮飾需一致。海豚只作為髮飾與圍裙圖樣，身體保持人類外觀。圖像由內建 ImageGen 產生。

## 主服三視

參照 [已核定主服](galgame-maid-turnaround.png)：暖白底、無文字、同一比例的正面／右側面／背面全身三視。深海藍與白色女僕裝，白色蕾絲頭飾避開單側高馬尾；不暴露胸口的圓領、短澎袖、白色圍裙及背後蝴蝶結、膝上裙襬與節制的水波滾邊。圍裙正面下側僅有一隻小小粉藍海豚刺繡。粉藍 `#A9D9EF` 與白色等寬橫條紋膝上襪，從大腿襪口延伸至腳踝；深藍圓鞋頭、單扣帶、低跟瑪莉珍鞋。藍色耳罩式耳機掛頸。三視服裝結構、配件位置與色票一致。

## 生活服三視

參照 [已核定生活服](galgame-casual-turnaround.png)：同一成年角色，暖白底、無文字、正面／右側面／背面全身三視。淺水藍寬鬆長袖連帽上衣，袖口略蓋住手；深藍短褲、白色短襪與室內拖鞋。高側馬尾稍鬆，銀色海豚髮飾保留。此服裝不穿主服的條紋膝上襪或瑪莉珍鞋。

參照 [已核定細節圖](galgame-detail-sheet.png) 與兩套三視。暖白底、無文字的角色設計細節頁：畏縮觀察、看到喜歡影片時短暫興奮、戴耳機專注、疲倦四種表情；銀色海豚髮飾、藍色耳罩式耳機、女僕裝圓領與荷葉邊、圍裙小海豚刺繡與背結、粉藍白條紋膝上襪、深藍瑪莉珍鞋局部放大。另畫生活服伏在桌上的「沒電趴窩」姿態，馬尾垂下，耳機擱在桌旁；該姿態仍穿短褲，露出大腿，不穿條紋膝上襪。不要加入 API 字樣、海豚耳朵、背鰭或尾巴。
