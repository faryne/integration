# galgame.tv 看板娘設定稿（三姐）

## 家族與定位

四姊妹的排行為 faryne.dev 長姊、neko.maid.tw 二姐、galgame.tv 三姐、steamloom.works 么妹。三姐對應 galgame.tv 的 OP／ED／PV 片庫，是會追新片、記住喜歡的曲子與畫面，再小聲把精彩片段推薦給姊妹的人。平常略微畏縮，說話前會先看對方反應；碰到喜歡的影片才短暫興奮起來，真正看片時又會安靜地專注。

「沒電趴窩」是她的固定狀態：當影片資料暫時取不到、暗指 YouTube API 額度不足時，她會伏在桌上，馬尾垂下，耳機滑到一旁，像暫時失去力氣。這是角色反應，不需在插畫上寫技術訊息。

## 外觀基準

- **年齡感與比例**：設定為成年女性，身高約 155 cm，比長姊 159 cm、二姐 160 cm 都更嬌小。身形輕巧，肩線窄，平常站姿微縮、手有時會抓住圍裙邊；不畫成 chibi 比例。
- **臉型與表情**：臉型柔和、臉頰略圓，眉毛和嘴角的細微變化容易看出情緒。平常有點不安、常先觀察他人；聽見喜歡的前奏時眼神會亮起，看片時目光穩定。
- **眼睛**：珊瑚粉色，眼型明亮、眼尾微翹；是深藍髮與藍白服裝之間的暖色焦點。
- **頭髮**：深海藍色長髮，綁單側高馬尾；放下時長度約到背中。髮尾略帶水藍色，平常馬尾有輕快的弧度；沒電時會鬆垂下來。
- **代表動物**：海豚。海豚元素只放在髮飾與服裝，不改變身體構造。馬尾根部有一枚小巧銀色海豚髮飾。

## 主服裝：深海藍與白色女僕裝

和兩位姊姊屬同一系列的女僕裝，以深海藍裙身、白色荷葉邊與白圍裙呈現。上身合身但不緊繃，圓領只露出鎖骨附近，短澎袖有白色袖口；裙襬在膝上，白色圍裙背後繫蝴蝶結。裙緣與圍裙邊緣有少量水波弧線，圍裙正面下側只繡一隻小小的粉藍海豚。小型白色蕾絲頭飾避開單側馬尾與銀色海豚髮飾。襪子為粉藍與白色橫條紋膝上襪，搭配深藍色、圓鞋頭與單扣帶的瑪莉珍鞋。藍色耳罩式耳機常掛在頸上，與銀色海豚髮飾一起構成識別重點。她維持純人類外觀，沒有背鰭、尾巴或其他海豚身體部位。

### 裙底、安全褲與膝上襪

- 裙內穿黑色或深海藍色安全褲，顏色須與粉藍白條紋襪明顯不同。褲管短於裙襬、藏在裙內；裙子被姿勢帶起時可以看見安全褲邊緣，但不畫成延伸到腿上的褲襪。
- 兩腳各穿一只獨立的粉藍白條紋膝上襪，襪口在膝蓋上方一段距離。站立時裙襬剛好壓住或遮到襪口；坐下或拉動裙襬時，襪口才會比較清楚。
- 安全褲褲口與兩只襪口之間保留一段完全沒有布料的腿部，呈現自然膚色。這段間隔不可填成襪子、褲襪、打底褲或與襪子同色的安全褲。

## 生活服

淺水藍寬鬆連帽上衣、深藍短褲、白短襪與室內拖鞋。袖子長到可以把手縮進去；單側高馬尾綁得比主服版本鬆一些，但銀色海豚髮飾保留。耳機可以放在桌邊。這套衣服適合坐著看片、蜷在椅子上，或沒電時伏在桌上的姿態。

## 表情、動作與道具

1. **平常**：略帶畏縮，肩膀微縮，手抓圍裙邊；珊瑚粉眼睛先觀察他人。
2. **看到喜歡的影片**：眼睛亮起、馬尾跟著晃，想分享又有點不好意思。
3. **看片中**：目光定在畫面，表情安靜而專注；耳機可戴起來。
4. **沒電趴窩**：伏在桌上，馬尾垂下，耳機滑到一旁；以姿勢表達資料額度暫時耗盡。

耳罩式耳機為主要工作道具，深藍與水藍配色。髮飾是簡化的銀色海豚輪廓，體積小，不做成立體背鰭。服裝只保留少量水波線條。

## 設定圖規格

- 深海藍與白色女僕裝正面、側面、背面全身三視，同一身高與服裝結構；粉藍白條紋膝上襪、圍裙小海豚及瑪莉珍鞋需在對應視角一致。
- 生活服正面、側面、背面全身三視，呈現連帽上衣、短褲、白短襪與拖鞋。
- 頭部細節：深海藍單側高馬尾、水藍髮尾、銀色海豚髮飾、珊瑚粉眼睛。
- 服裝細節：白色蕾絲頭飾、領口與澎袖、圍裙背結與小海豚刺繡、簡潔水波裙緣、裙內深色安全褲與腿部膚色間隔、兩只獨立的粉藍白條紋膝上襪、深藍瑪莉珍鞋、生活服布料。
- 道具與表情：藍色耳罩式耳機，以及畏縮、短暫興奮、專注、沒電趴窩四種狀態。
