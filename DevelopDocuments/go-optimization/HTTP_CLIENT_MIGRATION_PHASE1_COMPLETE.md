## 🔧 技術細節

### 新增的 HTTP 方法

#### DoRaw()
用於需要原始響應體的場景（HTML 解析、流式處理）

```go
content, err := client.DefaultHTTPClient().DoRaw(req)
```

#### DoRawWithStatus()
需要檢查 HTTP 狀態碼的場景

```go
content, statusCode, err := client.DefaultHTTPClient().DoRawWithStatus(req)
```
