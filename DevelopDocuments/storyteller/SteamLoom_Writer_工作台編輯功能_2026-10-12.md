# SteamLoom Writer 工作台編輯功能（建立／分冊／排序）規格

- 狀態：規格已確認，實作中（2026-10-12）
- Branch：`feat/steamloom-writer-workspace-editing`（已含 pnpm 固定版本 10.32.1）

## 範圍

| 做 | 不做（之後再說） |
|---|---|
| 建立：比照網站全部做——故事、圖像作品、冊、設定、設定集、資產集 | 圖像作品的內容編輯（Writer 沒有圖像編輯器，先只建立） |
| 分冊：故事移到某一冊／未分冊；設定移到某一設定集／未歸類 | 刪除、改名（冊／設定集的編輯）、狀態切換 |
| 排序：冊、冊內（含未分冊）的故事、設定集 | 設定本身（後端沒有 sort 欄位） |

## UI（比照網站側邊欄，不另創一套）

- **區塊標題列右側按鈕**（網站側邊欄同位置也有）：
  - 作品與冊：`排序`（切換排序模式）、`建立 ▾`（故事／圖像作品／冊）
  - 設定集：`排序`、`建立 ▾`（設定／設定集）
  - 資產集：`建立`（資產集）
- **排序模式**：該區塊每一列出現 ↑／↓ 按鈕，邊按邊存；再按一次 `排序` 結束。故事只在同一冊內移動，跨冊走「移動到冊」。
- **列的動作選單**（hover 出現 ⋮）：故事 →「移動到冊…」（列出各冊＋未分冊）；設定 →「移動到設定集…」。
- **建立流程**：彈出只問名稱的對話框 → 建立後側邊列重新整理並選中新項目。故事／設定建立後打開「編輯」分頁（目前仍唯讀，內容先靠 AI 助理寫）。
- 錯誤一律 snack；建立的對話框名稱空白時「建立」按鈕停用。

## User stories

1. 作者在 Writer 裡新開一冊「第二冊」，把三篇故事移進去，再調整三篇的順序。
2. 作者建立一篇空白故事「第十二話」，切到 AI 助理請它續寫。
3. 作者把「角色」設定集拉到「地點」上面，並把一篇未歸類的設定移進「角色」。

## 常見失敗與應對

| 情境 | 應對 |
|---|---|
| **排序／分冊用整篇 PUT，把 AI 助理剛寫的內容蓋回舊版**（網站目前的做法就有這個風險：送的是列表載入當下的內文） | 決策 1：改用只送變動欄位的 PATCH，由後端讀最新內容合併 |
| 每次排序都替每篇移動到的故事多存一個版本，編輯歷史出現一堆內容相同的「手動存檔」 | 決策 2：只改 sort／冊時不建立新版本 |
| 排序途中某一筆存檔失敗，順序一半新一半舊 | 每次操作完都重新抓側邊列資料，以伺服器為準；失敗跳 snack |
| 建立時名稱重複 | 允許（網站也允許），不擋 |
| Bearer token 被撤銷 | 沿用現有流程：`invalid_token` 才登出 |

## 待確認的決策（附建議）

1. **故事的局部更新**：新增 `PATCH /storyteller/projects/:project/stories/:story`，邏輯沿用 MCP `storyteller_patch_story`（後端讀最新內容再合併，不送內文）。Writer 的排序／分冊都走它。
   - 建議：**做**。網站的排序／分冊也有同樣風險，要不要一起改用 PATCH 請決定（建議一起改，改動只在網站的 `saveStoryPatch`）。
   - 代價：要部署後端，Writer 新版要等後端上線才能發。
2. **只改排序／分冊時不建立新版本**：建議做，跟決策 1 同一個 PATCH 路徑內判斷「內文、標題、摘要都沒變」就只更新欄位、不寫版本。冊的移動事件（作者動態用的）照常記錄。
3. **建立的範圍**：故事、冊、設定、設定集。圖像作品與資產集先不做。
4. **Writer 寫入的版本來源標籤**：透過 Bearer 打網站 API 寫入時，目前會記成網站的「手動存檔」。建議這次先不動（決策 2 之後排序／分冊不會產生版本，影響只剩建立）。

## 決策結果（2026-10-12 確認）

1. 新增 `PATCH /storyteller/projects/:project/stories/:story`，只接受 `sort`／`status`／`parent_id`（故事與冊共用，冊不能改 `parent_id`），**不寫入版本**；Writer 與網站的排序、移動到冊、狀態切換都改用它。
2. 排序／移動到冊／狀態切換不進編輯歷史，只記 audit：PATCH 路由註冊到 `story.update`／`story.move`／`story.reorder`／`volume.update`／`volume.reorder`，由 `resolvedWebStoryAction` 依前後差異細分（冊走 stories 路徑也會記成 `volume.*`）。
3. 建立比照網站全部做。
4. 版本來源標籤這次不動。
