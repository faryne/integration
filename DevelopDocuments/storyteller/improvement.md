# 功能改進內容

處理完畢後請將每項工作勾起來

- [x] 除了 AI Agent 的 mock 外，其他的 mock 都移除
- [x] 工作台的 `Well` 移除「建立專案」「建立 AI Agent」 button
- [x] 專案頁的的「專案 AI Agent」區塊移除
- [x] 故事列表中增加「刪除故事」 button 及實作。刪除操作比照「刪除專案」跳出 confirm dialog
- [x] 故事列表中可執行拖放以便安排章節順序
- [x] 「我的收藏」「我的工作台」需要增加登入檢查
- [x] 故事頁要標上作者筆名部分，如果沒有填寫 storyteller_user 的話則以登入時使用的 username 為主
- [x] 使用者按下登入後，如果發現還沒設定 `storyteller_user` 資料時，跳出對話框提示使用者填入想要的筆名後再繼續操作。使用者不能取消。即使使用者繞過沒填寫，登出後下次重新登入也會重複前述流程。
- [x] 故事頁中的收藏與評分在未登入狀態下點擊時需提示登入
- [x] 增加一個作者公開頁面，列出使用者「公開」的故事專案（需做分頁），路由為 `/storyteller/user/:username`。並且在故事頁中出現作者名稱的地方設定連結到作者頁。
- [x] 故事頁中列出該「專案」所有故事總文字數目
- [x] `StorytellerLayout` 需要處理行動版的問題。目前至少發現 Header 區塊在手機畫面上的 Menu 會顯得相當擁擠。
