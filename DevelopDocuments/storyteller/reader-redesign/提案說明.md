# Storyteller 閱讀頁重構提案

- 日期：2026-09-12
- branch：`codex/storyteller-reader-redesign`
- 狀態：需求已定案，正式實作已完成於本 branch，待 review

## 結論

閱讀頁應從目前的「作品詳情＋索引＋文章」三欄工作台，改成以章節內容為中心的沉浸式 reader。

本提案不移除既有目錄、書籤、本篇大綱、追蹤、評分、版本歷史或圖片閱讀能力，而是重新安排資訊層級：讀者打開章節後，首屏先看到標題與正文；管理與社交操作需要時再展開。

## 正式實作摘要

- `Reader.tsx` 已改用 overlay Drawer，移除會擠壓正文的 desktop Grid 索引與右下角 floating actions。
- 新增 `StorytellerReaderToolbar.tsx`，集中作品資訊、閱讀進度、書籤編輯與閱讀設定；mobile 的作品資訊／閱讀設定改用 bottom sheet。
- 新增 `useStorytellerReaderPreferences.ts`，以 localStorage 保存字體風格、字級、行距與正文寬度，並驗證舊資料是否仍為允許值。
- 文字作品已完成 desktop／mobile 共用的「編輯書籤／完成」模式；非編輯狀態只顯示不可操作的既有書籤標記。
- 篇章導覽改為 fixed bottom bar；desktop 顯示上一篇／置中的作品目錄／下一篇，mobile 保留上一篇／下一篇。
- 圖像作品保留既有 viewer、scrubber、lightbox 與頁面書籤，套用相同 reading bar 與 overlay 導覽。
- 閱讀內容外層統一移除卡片邊框與底色，文字篇章、圖片話皆直接融入閱讀頁；圖片 viewer 自身保留極淡 inset 邊界，避免透明或大面積淺色圖片與頁面背景混在一起。只有未選到內容的空狀態維持原本卡片樣式。
- 網站色系從 footer 移到共用 header，與原本明暗模式整併為單一「外觀設定」入口；footer 只保留品牌與社群資訊。
- 工作台 sidebar footer 原有的第二套色系選擇同步移除，避免 header、footer 與工作台出現三個入口。
- 工作台 sidebar 原有的色系選擇同步移除，避免同一個全站設定存在第二個入口。

### 變更邊界

閱讀頁不另刻 header／footer；這次只調整共用 shell 的外觀設定入口，因此首頁與其他 Storyteller 頁面也會得到同一個入口。

- Mockup 沿用共用 shell；header 的外觀設定與 footer 移除色票是全站一致調整，其餘 header／footer 結構不變。
- 新增的 sticky reading bar 位於 `Reader.tsx` 內容區內、共用 header 下方。
- 作品資訊 Popover、閱讀導覽與閱讀設定皆為 Reader-local component。
- footer 保留品牌與社群資訊，但移除大面積色票；色系控制與明暗模式集中到 header 的外觀設定 Popover，不必先捲到文章底端。
- 不另改 theme token 或 localStorage 邏輯；首頁、工作台與編輯頁只會看到入口位置調整，不會改變既有配色結果。

## 現況問題

### 1. 首屏被作品層級資訊占用

目前作品名稱、簡介、公開狀態、作者、篇數、字數、分級、標籤、追蹤與評分全部常駐在章節上方。資訊本身有價值，但不是每次換章都需要重新閱讀，長篇連續閱讀時會成為重複阻力。

### 2. 開啟索引會改變正文欄寬

桌面索引使用 Grid 占據約三分之一寬度，開關索引會讓文章重新換行。讀者只是暫時找章節，卻必須承受閱讀位置與視覺節奏改變。

### 3. 所有功能同時競爭注意力

目錄／書籤／大綱、追蹤專案、追蹤作者、評分、版本歷史、逐行書籤和篇章導覽都位於同一層級。功能齊全，但畫面不像閱讀器，更接近作品管理頁。

### 4. 閱讀設定缺少集中入口

網站已有主題切換，但正文的字級、行距與閱讀寬度沒有放在同一個閱讀情境中調整。對長篇中文內容而言，這三項比卡片樣式更直接影響閱讀舒適度。

## 定案方向

### 1. 正文欄寬固定，不受導覽開關影響

- 正文預設 measure 約 720px，置中顯示。
- 目錄／大綱／書籤改為左側 overlay panel，不占 Grid 欄位。
- panel 開關不改變文章換行，也不讓讀者失去目前閱讀位置。
- 寬螢幕未來可提供「釘選」選項，但預設仍是 overlay。

### 2. 作品資訊降為次要層

- 全站 header 下方增加精簡的 sticky reading bar。
- 左側顯示「目錄」與作品名稱；點作品名稱才展開簡介、標籤、作者、追蹤與評分。
- 中間顯示目前篇章名稱，讓長文捲動後仍知道自己正在讀哪一篇。
- 桌面右側顯示本篇閱讀進度、「編輯書籤」與閱讀設定；mobile 將「編輯書籤」放到篇章列。目錄、本篇大綱與書籤清單共用左側閱讀導覽入口。

這不是刪除作品資訊，而是區分「進入作品」與「閱讀章節」兩種任務。作品首頁已獨立承載完整 Hero、作品資訊與章節目錄；進入章節後只保留閱讀所需資訊。

### 3. 章節標題成為首屏主角

- 文章頂端只保留作品連結、章節標題、短摘要、作者、更新時間與版本歷史。
- 分級與 tags 不在每個章節頂端重複出現。
- 正文不再包在明顯的 bordered Paper 裡，讓頁面本身成為閱讀紙張，減少「卡片裡再放文章」的後台感。

### 4. 導覽整合為單一 panel

左側閱讀導覽提供三個 tab：

| Tab | 內容 |
| --- | --- |
| 目錄 | 分冊與篇章清單，標示目前篇章 |
| 本篇大綱 | 解析文章標題，顯示目前閱讀段落並支援跳轉 |
| 書籤 | 跨篇書籤與內容摘要 |

桌面與 mobile 共用同一套資訊架構；mobile 使用相同 panel 或 bottom sheet，不另造一套命名。

Reading bar 不另外提供「書籤」按鈕。書籤屬於內容導覽的一部分，與目錄、大綱共用單一「目錄」入口；書籤數量顯示在 panel 內的「書籤」tab，避免同一個 panel 出現兩個開啟入口。

### 5. 集中式閱讀設定

sticky reading bar 的 `Aa` 開啟設定 Popover：

- 字體：系統字體（預設）／黑體／明體；使用跨平台 font stack，不額外下載 Web Font。
- 字體大小：15～24px。
- 行距：緊／適中／寬。
- 頁面寬度：窄／適中／寬。

背景與深淺色不放進 Reader-local 設定，完整沿用網站既有 theme 與頁首夜間模式，避免出現「網站是黃銅色、正文卻是另一套紙張色」的雙重狀態。正式實作時只以 localStorage 保存字級、行距與頁寬，不寫入帳號或作品資料。

### 6. 逐段書籤降低常駐存在感

- 桌面與 mobile 都提供明確的「編輯書籤」按鈕；開啟後按鈕改為「完成」。
- 編輯模式中，每個未收藏段落顯示「加入書籤」，已收藏段落顯示「移除書籤」，不使用 hover、隱藏手勢或 scroll position 推算目標。
- 關閉編輯模式後，未收藏段落的操作全部隱藏，只保留已收藏段落的 compact gutter 狀態標記；標記不可直接點擊移除，避免加入與移除規則不對稱。
- desktop 的編輯操作顯示在段落左側 gutter；mobile 因寬度不足，操作按鈕直接顯示在該段文字上方，離開編輯模式後回到左側 compact 標記。
- 書籤仍錨定既有 line／block，不改後端資料模型。
- 新增／移除使用 Snackbar／toast 回饋，不開 modal。

### 7. 閱讀進度與篇章導覽

- 頁面最上方加入 3px reading progress，不占內容空間。
- sticky reading bar 的 `Aa` 左側同步顯示整數百分比（例如 `14%`），讓進度不只依賴細線判讀；桌面與 mobile 使用同一位置與計算結果。
- 上一篇／下一篇改為固定在 viewport 底端的精簡文字導覽，不再使用三張等寬卡片，長篇閱讀時不必先捲到頁尾。
- 中間「作品／回到作品目錄」兩行在 desktop 完整水平置中；mobile 為避免擁擠，目錄仍由 sticky bar 開啟。
- 正文與全站 footer 都保留 fixed bar 高度的底部空間，最後一段內容與 footer 不會被遮住。

## Mockup 可操作項目

桌面版開啟 `index.html`；行動版可直接開啟 `mobile.html`，以 390px／430px 裝置框檢視，不需要手動縮放瀏覽器。

可以操作：

- 從單一「目錄」入口開啟／關閉閱讀導覽，切換目錄、本篇大綱與書籤。
- 點大綱跳到示範段落。
- 點作品名稱展開作品資訊、追蹤與評分區。
- 調整字體大小、行距與正文寬度；背景跟隨網站 theme。
- 開啟「編輯書籤」，直接在各段落點擊「加入書籤」或「移除書籤」，完成後只顯示已收藏標記。
- 捲動畫面觀察 sticky reading bar 與頂端閱讀進度。
- 縮窄瀏覽器檢查 mobile 排版。

行動版差異：

- 作品資訊與閱讀設定使用 bottom sheet，避免小螢幕 Popover 定位與內容高度不足。
- 目錄／大綱／書籤仍使用左側 Drawer，維持章節清單的垂直瀏覽空間。
- 作品 Hero 改為左對齊；篇章列提供「編輯書籤／完成」，編輯期間在各段落顯示明確操作。
- fixed bottom bar 只保留上一篇／下一篇；作品目錄由 sticky reading bar 開啟。

## 與既有功能的映射

| 既有功能 | 提案位置 | 資料／行為是否改變 |
| --- | --- | --- |
| 作品 Hero | 作品名稱 Popover；完整資訊可留作品首頁 | 否 |
| 展開／收起索引 | sticky bar 的「目錄」 | 僅改呈現方式 |
| 目錄／書籤／本篇大綱 | 左側閱讀導覽 tabs | 否 |
| 追蹤專案／作者、評分 | 作品資訊 Popover | 否 |
| 版本歷史 | 章節 metadata | 否 |
| 逐行書籤 | 「編輯書籤」模式中的逐段操作；關閉後只留已收藏標記 | 否 |
| 上一篇／本篇／下一篇 cards | fixed bottom bar；desktop 中間改為作品目錄 | 僅改呈現方式 |
| footer 網站色票／header 明暗模式 | header「外觀設定」Popover 內的明暗模式與網站色系 | 否 |
| 圖片話閱讀 | 沿用既有 viewer，套用相同 reading bar／導覽 panel | 第一階段不改 viewer |
| 私人預覽／分享連結／限制級 gate | 進入內容前仍沿用既有判斷 | 否 |

## 建議實作拆分

### Phase 1：版面骨架

- 從 `Reader.tsx` 拆出 `ReaderNavigationPanel`、`ReaderToolbar`、`ReaderWorkPopover` 與 `ReaderSettingsPopover`。
- 沿用既有 `StorytellerShell` header／footer；共用 shell 僅將 footer 色票搬進 header 外觀設定，不為 Reader 建立另一套 theme state。
- desktop index 由 Grid column 改為 overlay Drawer，正文 measure 固定。
- 將作品 Hero metadata 移入作品 Popover。
- 文字閱讀正文移除外層 bordered Paper，重做 header 與 fixed bottom navigation。

### Phase 2：閱讀偏好

- 建立共用 `useStorytellerReaderPreferences` hook。
- 只保存 font family preset、font size、line height 與 measure。
- 背景、色票與 dark mode 直接使用主站 theme，不建立 Reader 專用 theme state。

### Phase 3：細節與 mobile

- 實作 desktop／mobile 共用的 bookmark edit mode；mobile 切換為段落上方的明確文字按鈕。
- mobile 導覽 panel、sticky bar 與 safe-area。
- 將相同骨架套到 image episode reader；圖片 viewport、scrubber 和 lightbox 行為維持不變。

## Review 重點

- overlay 導覽開關後，正文寬度、換行與 scroll position 是否完全不變。
- sticky reading bar 是否在手機上過高，或與全站 header 重複占用空間。
- 作品資訊 Popover 是否容得下 tags、追蹤、評分與私人／分享狀態。
- 字級、行距與頁寬偏好是否只作用在 Reader；背景是否完整跟隨既有 MUI theme。
- 「編輯書籤／完成」狀態是否在 desktop／mobile 同步；每個按鈕是否精確綁定自身段落；離開模式後已收藏標記是否為不可操作狀態，所有新增／移除都只能在編輯模式發生。
- 歷史版本 banner、限制級 gate、loading/error 與 image episode 是否仍能放入新骨架。

## 本提案刻意不做

- 不改公開 API、分享路由或書籤資料模型。
- 不新增留言、即時閱讀人數、AI 摘要或讀者社群功能。
- 不在第一階段重寫 image lightbox／scrubber。
- 不移除 StorytellerShell；先沿用全站導覽與既有 theme，再處理閱讀頁內層。
- 不為閱讀頁建立專用 header／footer；全站共用外觀入口，避免不同頁面出現兩套操作位置。
