# 初衷

沒什麼，就只是自己想要寫小說而已！

因此一開始著重的項目在於編輯器及閱讀頁而已。

# 功能介紹

## 工作台
1. 專案的建立/刪除/編輯
2. Skill 的設定：設定專用的 SKill ，使其專注於處理特定任務
3. MCP & PAT ：提供設定 Personnal Access Token (PAT) 的功能，以讓使用者可以透過自己訂閱的 AI 服務使用 MCP 介面操作。
4. API KEY 的設定：提供設定 API KEY 的功能，可以讓使用者透過 BYOK 帶入自己的 APIKEY 輔助自己的寫作。
5. AI Usage：若在站上使用了 AI 服務，會統計每次對話中的所耗用的 token 數並且粗略估算使用費用。

## 專案
1. 建立故事/圖像畫廊作品以及故事冊
2. 建立設定/設定集
3. 建立資產/資產集
4. 作品的排序與分冊處理
5. 在故事/設定中使用 AI 助理協助編寫內容
6. 故事/設定可使用作者備注以及書籤功能標示用途
7. 故事/設定編輯器可使用絕大部分 markdown 語法
8. 故事可使用腳註功能，作為給讀者使用的相關補充資訊。
9. 具有編輯歷史功能，可以追蹤過程中的修改差異

## 閱讀頁
1. 具有閱讀進度條，可以知道進度（目前沒做成記錄）
2. 可在任一段落做成書籤，點擊書籤可快速跳到段落。
3. 具有索引功能，點擊標題可快速跳至特定標題。
4. 具有編輯歷史，可讓讀者觀看故事的編修變化

## MCP
1. 可以進行故事的新增修改刪除、文章的段落編輯
2. 可以進行專案的新增修改刪除
3. 可以進行設定的新增修改刪除
4. 可以進行資產的新增修改刪除

## AI 助理
1. 續寫、擴充、重寫等 AI 快速功能
2. 搭配 Skill 產生出想要的東西
3. 可以使用 `@thisStory` 、 `@story:[故事標題]` 、 `@thisLore` 、 `@lore:[設定標題]` 搭配讀取相應內容輔助思考

# User Story

## 純粹寫故事
沒什麼好說的就是人類在編輯器內讀寫故事。也可以是人類在自己的電腦寫好初稿後在自己的機器上透過安裝的 Codex / Grok / Claude 潤稿後透過 MCP 更新。

## 由 AI 擔當 Ghost Writer
使用者使用 Claude / Codex / Grok 產生劇情故事，並透過 MCP 更新。

## 使用者寫好設定由 AI 讀取詳細設定後開始產生劇情
使用者寫好設定內容，包含劇情走向等，讓 AI 讀取後自動寫出劇情發佈。

## 使用者寫出軟體開發需求
使用者將軟體的需求以自然語言方式寫成放到上面，AI 可以讀取其中的規格開始設計撰寫軟體程式碼。中途的需求變更亦有編輯歷史可以參考。
