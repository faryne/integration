DEVELOPER

MCP 連接

讓外部 AI 工具直接讀寫你的創作專案、故事內容與世界觀設定。

  1. 1

    選擇連線方式

    依你要連的工具選一種，接著會跳出對應的設定視窗。

  2. 2

    設定你的工具

    選好連線方式後，在跳出的視窗裡完成設定。

    已設定：OAuth · Claude.ai
    在 Claude.ai 按下「允許」後就完成了，可以到 OAuth Token 頁確認。

  3. 3

    安裝 Skill 選用

    SKILL.md 告訴 AI 有哪些工具、什麼時候該用、寫入前要注意什麼；內容跟連線方式無關。放進 Claude Code、Codex 等工具的 skill 目錄，或上傳到 Claude.ai 的 Skills 即可。

MCP 連線位址：https://steamloom.works/mcp・目前不支援 SSE，若工具連線卡住可能是這個原因。

步驟 2 · OAuth 授權

要連哪個工具？

https://steamloom.works/mcp
  1. 到 Claude.ai 的設定，新增自訂 connector
  2. 名稱填 Steamloom，網址貼上上面的 MCP 位址
  3. 按連線後會跳到 Steamloom 授權頁，確認帳號後按「允許」
  1. 到 ChatGPT 的設定，新增自訂 connector（需要開啟開發者模式）
  2. 網址貼上上面的 MCP 位址，驗證方式選 OAuth
  3. 跳到 Steamloom 授權頁後按「允許」

在終端機執行：

claude mcp add --transport http steamloom https://steamloom.works/mcp
  1. 在 Claude Code 裡輸入 /mcp，選 steamloom 進行驗證
  2. 瀏覽器會跳到 Steamloom 授權頁，按「允許」
  1. 在工具裡新增遠端 MCP server，貼上上面的 MCP 位址
  2. 工具會自動註冊並開啟 Steamloom 授權頁，按「允許」
  3. 如果工具要求手動填 Client ID／Client Secret，代表它不支援自動註冊，請改用 Personal Access Token
