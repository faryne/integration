MCP 連接

讓外部 AI 工具直接讀寫你的創作專案、故事內容與世界觀設定。

MCP 連線位址

https://steamloom.works/mcp

目前不支援 SSE，若工具連線卡住可能是這個原因。

推薦

OAuth 授權

適用 Claude.ai、ChatGPT 等網頁版服務，以及支援 OAuth 的 MCP client。

  1. 在工具裡新增自訂 connector，貼上上方網址
  2. 跳出 Steamloom 授權頁，確認後按「允許」
  3. 完成，之後可在「OAuth Token」頁管理或撤銷

不需要填 Client ID／Client Secret，工具會自動向 Steamloom 註冊。若工具要求手動填寫，代表它不支援自動註冊，請改用 Personal Access Token。

Personal Access Token

適用 Codex CLI 等需要在設定檔寫入 token 的本機工具。

{
  "mcpServers": {
    "steamloom": {
      "url": "https://steamloom.works/mcp",
      "headers": {
        "Authorization": "Bearer <YOUR_PAT>"
      }
    }
  }
}
