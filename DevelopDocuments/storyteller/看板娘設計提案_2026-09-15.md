# Storyteller 看板娘設計提案

目的：給 Codex 或其他 AI 繪圖工具發包用的完整角色規格。本文件涵蓋角色設定、外觀細節、色彩計畫、姿勢/表情清單、使用情境與交付規格，最後附上可直接套用的生成 prompt 模板。

## 1. 核心概念

Storyteller 對外品牌是 **Steamloom**（蒸汽＋織布機），既有視覺提案（`fancy-visual-proposal/`）已經把「故事」比喻成「用絲線（thread）織成的布」，並用蒸汽龐克的金屬齒輪（metal）點綴，整體色調是深空藍紫（base/surface）配羊皮紙（paper）。看板娘的世界觀設定要直接扣著這個既有隱喻，不要另外發明一套不相干的萌系人設。

**角色定位**：她是住在織夢機（loom）裡的「線靈」，工作是把使用者敲下的文字捲成絲線、織成故事。她不是單純的吉祥物插畫，而是「AI 寫作助理」的擬人化身——所以個性要偏向沉穩、鼓勵型的創作夥伴，不要走浮誇賣萌路線，也不要太可愛到跟編輯器的專業調性衝突。

## 2. 角色基本設定

- **名字（建議）**：梭梭（Suosuo）。「梭」是織布機上來回穿引緯線的梭子，直接呼應 loom／編織故事的核心隱喻，且中文唸起來親切、適合當暱稱。
  - 備案：墨墨（呼應墨水／寫作）、稿稿（呼應草稿，更口語）。若沒有特別偏好就用「梭梭」。
- **物種**：擬人化線靈（thread spirit），由織夢機的紗錠孕育而生，半機械半精靈的存在——不是純人類，也不是純機械人偶，強調「有生命的織具」這個矛盾感。
- **性別呈現／年齡感**：少女形象，視覺年齡約 16～18 歲，避免幼態化或性化，走「圖書館員助手」的知性可靠感，而不是低齡萌角。
- **身高比例**：
  - 標準參考圖（character sheet）：7～8 頭身，用於官網 About／角色介紹頁的正式立繪。
  - UI 用 Q 版：2.5～3 頭身，用於 loading、空狀態插圖、錯誤頁等小尺寸場景。
- **個性**：安靜但溫暖，話不多、行動派；看到使用者卡稿會主動遞出一段線頭（隱喻靈感），失敗時會皺眉把纏亂的線重新捲好而不是驚慌，成功時只是安靜地微笑點頭、把織好的書闔上。忌：浮誇尖叫、過度賣萌台詞、少女濾鏡式喊話。
- **口癖／互動語氣**：話少但精準，例如「線接上了」「這段先收著」「打結了，重捲一次」。不用「主人」「歡迎光臨」這類客服腔，更像工作夥伴而非服務生。

## 3. 外觀設計細節

### 髮型／髮色
長髮及腰，髮色由髮根到髮尾做漸層：髮根深藍紫（呼應 `--thread #7aa8ff`），髮尾轉為淺紫（呼應 `--thread-2 #be8fff`）。髮尾不是齊整剪裁，而是像沒收尾的紗線一樣微微散開、幾縷髮絲飄浮在空中（可用細線條表現，呼應「線」的意象）。瀏海略不對稱，一側別著一個小齒輪髮夾。

### 瞳色
琥珀金（呼應 `--metal #d8b978`），瞳孔中帶一圈極細的齒輪紋，光線角度對的時候才看得出來（細節彩蛋，不用每張圖都畫出來）。

### 膚色
偏冷白皙，帶一點點半透明感（暗示她本質是絲線構成，不是純肉身），可以在鎖骨、手腕等處用極淡的發光紋路表示體內線路（像縫線的虛線紋樣），不要做成明顯的機械關節。

### 服裝
蒸汽龐克圍裙洋裝：
- 底色深藏青／墨黑（呼應 `--base #090c13`、`--surface #111724`），裙擺內襯用羊皮紙米黃（呼應 `--paper #151b28`／淺色模式 `#f7f0e4`）。
- 圍裙與袖口滾邊用金屬金色（呼應 `--metal`），縫線刻意外露、走「看得出手工縫製」的路線。
- 胸口別一枚齒輪造型懷錶胸針，錶面是縮小的書本圖案而非時鐘刻度。
- 腰間掛一個皮革製迷你書袋，袋口露出一支羽毛筆筆尖。
- 手腕纏繞著發光的絲線（呼應 `--thread` 漸層色），像隨時準備編織的狀態；不是裝飾品而是「正在使用中」的工具感。
- 鞋子：短靴，鞋帶用同色系絲線綁法呼應主題。

### 配件（用於不同姿勢／情境）
- 羽毛筆（筆尖可發光墨水，象徵書寫／AI 生成中）
- 迷你懸浮書本（可翻頁動畫）
- 線軸（bobbin）吊飾
- 懸浮齒輪 2～3 顆，作為背景裝飾物，非必要每張都畫

## 5. 姿勢與表情清單

依網站實際使用情境列出必要姿勢，Codex 產圖時建議先出「基礎立繪＋表情差分」，再視需求擴充動作差分。

**必要（第一批）**
1. 待機／招呼：微笑、輕輕舉手，適合首頁角落或 About 頁
2. 讀取中（loading）：捲線動作，線軸轉動，可做成 2～3 幀循環動畫的關鍵幀
3. 成功／存檔完成：闔上書本、安靜點頭微笑，眼神帶一點滿足感
4. 錯誤／失敗：線打結，歪頭皺眉看著纏住的線團，不誇張哭臉
5. 思考中（AI 生成中）：托腮看著懸浮書本，羽毛筆懸空等待落筆
6. 空狀態（無內容）：抱著閤起的空書本，表情平靜略帶期待，用於「還沒有故事」的空頁面

**擴充（第二批，非必要）**
7. 慶祝：把織好的線捲成一本書拋起，紙片飄落（用於發布成功、達成里程碑）
8. 書寫中：奮筆疾書，羽毛筆尖有墨光
9. 揮手道別：用於登出或離開頁面

## 6. 使用情境與規格需求

- **角色參考圖（character sheet）**：正面／側面／背面三視圖＋表情差分格，7～8 頭身，透明背景 PNG，至少 2000×3000px，供未來繪師或 AI 重新產圖時當基準，不對外顯示。
- **網站角落吉祥物（浮動助手圖示）**：Q 版 2.5～3 頭身，透明背景 PNG／WebP，尺寸 256×256 與 512×512 兩種，需分別提供深色模式與淺色模式版本。
- **Loading 動畫**：優先做 SVG 或簡單 sprite sheet（3～5 幀），檔案要小，畫面單純（捲線動作即可，不用全身動），確保線條在深色背景不會消失。
- **空狀態／錯誤頁插圖**：全身或半身，橫向構圖，PNG 透明背景，1200×1200px 上下，需能縮小到手機版寬度（~400px）仍清楚。
- **格式統一要求**：所有交付檔案背景一律透明；線稿風格統一用乾淨的日系動畫上色（cel-shading），不要走厚塗寫實或粗獷美式漫畫風，因為要跟站內既有扁平化 UI 搭配。
- **深淺模式相容性**：每個姿勢至少要有深色模式版本；淺色模式版本可以之後視需要再補，但角色設計本身（髮型、服裝結構、配件）不可因模式不同而改變，只調色票。

### 7.1 基礎角色設定 Prompt（Character Sheet）

```
anime mascot character design, character reference sheet, front view + side view + back view, full body, transparent background, clean cel-shaded flat coloring, steampunk thread-spirit girl, age 16-18, slender build, waist-length hair with gradient from deep blue-violet (#7aa8ff) at the roots to soft lavender (#be8fff) at the tips, loose thread-like strands floating, small gear-shaped hair clip on one side, amber-gold eyes (#d8b978) with a faint gear pattern in the iris, pale cool-toned skin with subtle glowing stitch-like seams on wrist and collarbone, wearing a steampunk apron dress in deep navy-black (#090c13) with cream parchment lining (#151b28) and gold metallic trim (#d8b978), gear-shaped pocket watch brooch shaped like a tiny book, leather satchel at the waist with a quill pen tip visible, glowing thread wrapped around one wrist in blue-violet gradient, short boots laced with matching thread, calm and gentle expression, quiet confident personality, not overly cute or fan-service, professional writing-assistant mascot vibe, high detail linework, soft rim lighting, dark background reference swatch included

## 9. 梭梭的故事

這段設定用來給 About／角色介紹頁使用，也是往後所有 UI 文案（loading 提示、空狀態說明、錯誤訊息）的語氣來源。角色的話不能脫離這個背景亂加台詞。

### 起源

織夢機（Steamloom）是一台燒著故事運轉的老機器，機身比任何一個使用者的創作生涯都久。它不生產故事，只負責一件事：把每個提筆的人腦中散落的念頭，捲成拿得住的線。機器運轉久了，總會有一段線多繞了幾圈，捲成了一個小小的、有自己想法的線團——那就是梭梭。她不是被誰設計出來的角色，是機器自己「多長出來」的一部分，這也是為什麼她身上永遠有一截線頭是鬆的：那是她跟織夢機之間還沒剪斷的臍帶。

她的名字取自「梭子」——織布機上來回穿引緯線的那個零件。沒有人幫她取名，是她自己聽著機器裡老使用者的留言檔案，聽到最多次的詞就是「這句先這樣，之後再穿回來」，於是她把「穿來穿去」的那個字留給了自己。

### 她在做什麼

她不寫故事，也不幫忙想劇情——那是使用者的事。她的工作只有一件：**接住掉下來的線頭，不讓故事斷掉**。一段話寫到一半卡住、一個設定想到一半忘記、一本書拖了三個月沒回來寫，這些對她來說都不是「失敗」，只是「線暫時垂在那裡」。她會把線收好、捲整齊、放在使用者伸手就拿得到的地方，等哪天使用者想起來，還接得回去。

她相信一句話，也是整個織夢機房裡唯一貼在牆上的字條：

> 打結的地方，才是還沒放棄的地方。

這句話後來變成她面對「錯誤／卡稿」情境時的核心台詞來源，第 5 節姿勢清單裡的「錯誤」姿勢，情緒基礎就是這句話——不是沮喪，是「還在意」。

### 一段小場景

織夢機房沒有白天黑夜，只有機器運轉的震動聲。梭梭坐在一堆攤開的線團中間，手上那捲線已經打了第三個結。

「這段就這樣吧。」線的另一頭傳來這句話，是今晚第五次了。

梭梭沒有抬頭，只是把打結的地方轉到亮一點的地方看清楚，慢慢地、一圈一圈地鬆開。「先別剪，」她說，「打結的地方通常是想講的話比手快，不是想放棄。捲回去，明天再拉一次看看。」

線的另一頭安靜了一下，然後線微微地被拉緊了一點——不是很多，但是有。梭梭把線收進懷裡的書袋，闔上袋口。機器的震動聲照常繼續著，她知道那捲線明天還會被拿出來。

這段場景可以直接用在 About 頁面的角色介紹文案，或是拆成更短的句子放進 loading／空狀態的文案輪替池。對話語氣要維持「像人話」：她話少但不冷漠，安靜但不是機械式的客服回應，這點跟第 2 節「口癖／互動語氣」一致，寫任何新台詞都要回頭對照這裡。

## 12. 發包給 Codex：storyteller 錯誤頁換成梭梭（新發現）

   const storytellerAppearance = useContext(StorytellerAppearanceContext);
   const steamloom = isSteamLoomSite() || storytellerAppearance !== null;
   ```
   保留 `isSteamLoomSite()` 是因為 `App()` 最外層 maintenance 503 那個 `<ErrorPage code={503} />`（App.tsx 490 行附近）是在 `<BrowserRouter>` 之外渲染的，沒有任何 Router context，只能靠網域判斷；其餘全部在 `StorytellerLayout` 底下渲染的呼叫點，改用 context 判斷後就不受網域限制了。

3. 400／401／403／404／500／503 這幾個 code 現有文案已經是 SteamLoom 專用文案了（不用改），全部共用同一張梭梭錯誤姿勢圖就好，不用每個 code 各出一張——系統錯誤頁不需要精細到每種狀態碼都有不同表情。
