# 故事／設定共用編輯頁（網站 × SteamLoom Writer）

2026-10-14。網站的 StoryEditor、LoreEditor 與 Writer 的文字編輯頁原本是三份各自實作的草稿／存檔邏輯與版面，收成同一套元件。

## 架構

`static_site/src/pages/storyteller/documentEditor/`（Writer 透過 alias 直接 import，CI 的 `paths` 已涵蓋整個目錄）：

| 檔案 | 用途 |
|---|---|
| `useDocumentEditing.ts` | 草稿、手動／自動存檔、屬性 PATCH、版本衝突、載入基準（marker backfill）、離開前判斷。存檔怎麼送交給 adapter |
| `webDocumentAdapter.ts` | 用網站 API hook 存故事／設定。網站與 Writer 的文字文件都用這份（Writer 經 `ApiProxy` 轉發） |
| `SteamLoomDocumentEditor.tsx` | 「編輯／編輯歷史」分頁＋頁首＋所見即所得編輯器（插入資產、大綱與書籤、底部狀態列與存檔） |
| `DocumentEditorHeader.tsx` | 衝突提示、標題、狀態、冊／設定集、署名（故事）、劇透與需先讀過（設定）、摘要 |
| `DocumentHistoryPanel.tsx` | 版本表格、兩版比對、回復（網站 API hook，Writer 經 proxy） |
| `EditorAutoSaveButton.tsx`／`autoSaveMinutes.ts` | 自動存檔間隔 |
| `documentEditorLabels.ts` | 介面文字；網站用預設中文，Writer 用 i18n 組一份（`lib/documentEditing.ts`） |
| `StorytellerDocumentEditorPage.tsx` | 網站專用：載入、登入／404、離開前確認、新文件建立後換網址、舊版 `/diff` 路由 |
| `useDocumentEditorAgentWorkspace.tsx` | 網站站內 AI 工作區接線（目前停用，程式碼保留） |

- `StoryEditor.tsx`／`LoreEditor.tsx` 只剩轉到 `StorytellerDocumentEditorPage` 的薄包裝（路由、`ProjectWorkspacePreview` 的 import 不用改）。
- 頁面外層等資料備齊才掛上編輯本體（以 `kind:id` 為 key）：`useDocumentEditing` 一開始拿到的就是真正的文件，換篇整個重建。
- Writer：`EditorPanel` 的文字文件用 `SteamLoomDocumentEditor`；圖像作品用同一個 hook＋`DocumentEditorHeader`，但存檔走 Go（`goDocumentAdapter`，存檔前要上傳本機圖）。Go 的 `Document` 補了 `sort`、`is_spoiler`、`depends_on`。

## 行為變化

- 網站的編輯歷史從右側抽屜改成分頁（跟 Writer 一致），切過去編輯器不卸載。舊版獨立頁（`my/project/...`）故事的 `.../diff` 網址對應「編輯歷史」分頁。
- 舊版獨立頁改用跟工作台相同的版面（頁首按鈕列＋底部工具列），不再是表單欄位。
- Writer 補上：大綱與書籤、插入資產、版本回復、設定的劇透與需先讀過。
- 伺服器上的內容變了（重新整理、別處改過）只在沒有未存檔內容時換上；原本網站會直接蓋掉未存檔的內容。
- 已存在的設定存檔不再帶 `status`／`collection_id`（兩者即時 PATCH，省略＝不變更），避免拿過期值蓋掉側邊列剛改的。
- 標題空白時手動存檔直接提示，不送後端（Writer 原本的行為）。
- 切換自動存檔間隔不再跳提示訊息。
- 站內 AI 套用提案：冊／設定集、狀態改走 PATCH，標題／摘要／內文以 `agent_apply` 存檔。

## 已知限制

- 「最新版本本身帶衝突標記時一進頁就提示」沒接（`EditingDocument.conflicted` 有欄位，兩端都沒填）；存檔當下回 `version_conflict` 的提示照常。
- 版本列表經 proxy 會帶完整內文，篇幅很長、版本很多時 Writer 開歷史分頁會比較慢。
