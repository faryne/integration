# 編輯區文字設定

- 狀態：規格待確認（`feature/storyteller-editor-typography-settings`）
- Mockup：`editor-typography-mockup/index.html`
- 範圍：故事編輯頁、設定集編輯頁、圖像作品「頁面描述」對話框

## User Story

- 作者長時間寫作，想把編輯區字放大、換成明體，不用每次靠瀏覽器縮放（縮放會連工具列、側欄一起變大）。
- 作者在手機上寫，想把字調小一點，一屏多看幾行。
- 閱讀頁的偏好跟寫作的偏好各自獨立：讀的時候 20px 明體，寫的時候 16px 黑體。

## 規格

| 項目 | 決定 |
|------|------|
| 設定項 | 字體大小（15～24）、字體（系統／黑體／明體）、行距（緊／適中／寬）。選項跟閱讀頁共用同一份清單 |
| 不含 | 頁面寬度：編輯區寬度由工作台版面（側欄、AI 面板）決定，圖像描述又在對話框裡，加了反而互相打架 |
| 預設值 | 16px／黑體／緊（1.7）。接近現在的樣子：現在是整站字體 Noto Sans TC、16px、行距 1.5，唯一可見差異是行距 1.5 → 1.7 |
| 儲存 | localStorage 新 key `storyteller-editor-preferences`，跟閱讀頁 `storyteller-reader-preferences` 分開；故事／設定集／圖像描述三處共用同一份 |
| 入口 | 編輯器文件工具列的工具區多一顆「文字設定」icon（`TextFields`，跟閱讀頁同一個圖示），排在語法說明／匯出旁邊 |
| 呈現 | 桌機用 Popover，手機用 bottom sheet，跟閱讀頁一樣 |
| 套用範圍 | 只套在正文編輯區（`.ProseMirror`）。標題用 em 計算，會跟著等比放大；工具列、bubble menu、斜線選單、AI 面板、大綱都不受影響。code block 保留等寬字體 |
| 即時生效 | 調整後編輯區立刻重排，不用存檔，也不影響作品資料 |

## 影響檔案

- `useStorytellerReaderPreferences.ts` → 改名 `useStorytellerTypographyPreferences.ts`，把 storage key／預設值參數化；閱讀頁與編輯區各包一層 hook。順便：
  - 寫入 localStorage 也包 try/catch（現在只有讀有包，Safari 無痕模式寫入會丟例外）
  - 改用模組層 store（`useSyncExternalStore`），同一頁開多個編輯器（工作台多分頁）時，改一處其他處會同步
- 新增 `StorytellerTypographySettings.tsx`：把閱讀頁 `settingsContent` 抽出來共用，`showMeasure` 控制要不要顯示頁面寬度
- 新增 `StorytellerTypographySettingsButton.tsx`：icon＋Popover／bottom sheet，閱讀頁與編輯區共用
- `StorytellerReaderToolbar.tsx`：改用上面兩個共用元件（575 行會縮短）
- `StorytellerWysiwygToolbar.tsx`：加入按鈕
- `StorytellerWysiwygEditor.tsx`：讀偏好、套到正文容器的 sx（覆蓋 `HEADING_TYPOGRAPHY_SX` 裡 `p` 寫死的 `lineHeight: 1.5`）
- `StoryEditor`／`LoreEditor`／`ImageEpisodeEditor`：不用改，都是用同一個 `StorytellerWysiwygEditor`

## 常見 fail 與應對

| 情境 | 應對 |
|------|------|
| localStorage 不能用（無痕、被封鎖） | 讀寫都 try/catch，退回預設值；這一頁內仍可調整，只是不會記住 |
| 舊值或被手改成不合法的值 | 沿用現有逐欄驗證，不合法的欄位退回預設 |
| 手機底部列被多一顆按鈕擠成兩行 | 上次量測（375px）時 AI 分頁還在，現在已隱藏，理論上剛好空出一顆。實作後實測，真的擠不下就把「匯出」跟「文字設定」收進一個「⋯」選單 |
| 大字級＋圖片文繞圖／表格 | 圖片寬度跟字級無關；表格已經是 `table-layout: fixed`，字放大只會換行，不會撐破 |
| 大綱／書籤跳轉位置跑掉 | `scrollMarginTop` 是固定 px，跟字級無關；實作後實測 24px＋寬行距的跳轉 |
| 圖像描述對話框 | 對話框裡的編輯器沒有 `toolbarExtra`，工具列只剩工具區，按鈕會直接出現，不用另外接 |

## 不做

- 編輯區寬度、背景色、段落間距
- 跟帳號同步（換裝置要重設）：閱讀頁也是只存本機，維持一致
