# 通用日曆元件（HolidayCalendar）

- 狀態：已實作（2026-10-02），在 `feature/holiday-calendar` 分支
- 檔案：`static_site/src/components/common/HolidayCalendar.tsx`（元件）、`holidayCalendar.ts`（型別與日期計算）
- Mockup：`holiday-calendar-mockup/index.html`（早期版本，含已廢棄的 csvUrl 狀態切換；畫面樣式仍適用）

## 用途

月曆元件，標出放假／上班／補班與節日名稱；沒傳資料時就是一般萬年曆。日期相關一律使用 `dayjs`。

## API

```ts
interface HolidayCalendarDay {
  date: Dayjs;
  isHoliday: boolean;
  note?: string; // 節日名稱、補假、補行上班…
}

// 依西元年分組，Map 與 Record 皆可
type HolidayCalendarData =
  | Map<number, HolidayCalendarDay[]>
  | Record<number, HolidayCalendarDay[]>;

interface HolidayCalendarProps {
  data?: HolidayCalendarData;                          // 沒傳或為空＝萬年曆
  onClick?: (date: Dayjs, day?: HolidayCalendarDay) => void; // day 為 undefined＝這天沒有資料
  disabledDates?: Dayjs[];                             // 只比對年月日，停用的日期不觸發 onClick
  isROCYear?: boolean;                                 // true 時年份顯示民國年
  initialMonth?: Dayjs;                                // 預設今天所在月份
}
```

使用範例（人事行政總處 CSV 需自行轉換，元件不負責抓取）：

```tsx
<HolidayCalendar
  data={new Map([[2027, days]])}
  isROCYear
  disabledDates={[dayjs("2027-02-11")]}
  onClick={(date, day) => console.log(date.format("YYYY-MM-DD"), day?.isHoliday)}
/>
```

## 畫面行為

- 月檢視固定 6 週；導覽有「上一年／上個月／下個月／下一年／今天」，**不限制範圍**（萬年曆可以一路切到民國前）。
- 有資料的日期：放假紅底紅字；週末但要上班顯示黃底＋「補班」徽章；平日上班一般樣式。備註顯示在日期下方（桌機最多 2 行、手機 1 行）。
- 沒資料的日期：週末只把日期標紅（萬年曆慣例），不上底色。
- 有資料時標題列顯示「放假／補班／上班」圖例（md 以上）。
- `disabledDates`：整格變淡＋斜線底紋、日期數字劃線、`cursor: not-allowed`、`aria-disabled`，保留放假／補班底色。
- 點擊：記住最後點的那天（外框標示）；點到前後月的日期會切換到那個月。
- 民國年：1912 起為「民國 N 年」，之前為「民國前 N 年」。
- 每格是 `<button role="gridcell">`，`aria-label` 帶完整描述，例如「民國116年2月20日 星期六 補班 補行上班」。

## 已確認的決策（2026-10-02）

- `csvUrl` 整個廢棄：人事行政總處 CSV 沒有 CORS header，原本要做的後端代理也一併不做；資料由使用端自行準備。
- 人事行政總處 CSV 格式備忘（自行轉換時參考）：UTF-8 含 BOM，欄位 `西元日期,星期,是否放假,備註`，日期 `YYYYMMDD`，`0`＝上班、`2`＝放假；「Google 行事曆專用」版欄位不同。

## 已知 Bug 記錄

- **快速連點年／月導覽會吃掉點擊**：現象為連點「上一年」多次只退一年。Root cause：`setMonth(month.add(...))` 讀到同一次 render 的舊 `month`。解法：改用函式型 updater `setMonth((current) => current.add(...))`。狀態：已修（實作時發現，未進版前修正）。
