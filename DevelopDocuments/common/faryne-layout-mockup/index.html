faryne.dev 內頁 Layout Mockup 取代 DefaultLayout 的藍白 AppBar
改動重點
  1. Header 改成跟首頁 LabLayout 同一條「墨色玻璃」列：深墨底＋青綠 accent，淺／深色模式都不變；從首頁點進內頁不再像換了一個網站。
  2. 下拉選單改成 mega menu：navigation.ts 本來就有 description 卻沒用到，這裡直接顯示；外站連結帶 ↗，目前所在頁會標示。
  3. 目前所在分類在 header 上用青綠底線標示（例：在 /data/* 時「資料」亮起）。
  4. Header 下方一條 breadcrumb：由 navigation.ts 自動推導（首頁 / 分類 / 頁面），各頁不用自己再刻；頁面原本的大標題保留。
  5. 拿掉 min-width: 1280px，改 max-width 1280 置中、手機版漢堡選單開 drawer。
  6. 頁面底色修正：現在內頁吃到 Vite 預設 index.css 的 #242424 深灰底配白卡片；改成跟 MUI palette 一致的淺色／深色兩套 token。
  7. Footer 改成跟首頁同款深墨底，沿用 FooterNavigation 四欄。
  8. Header 右側色彩模式切換：跟隨系統（預設）／淺色／深色三選一，存 localStorage。控制列的「系統：淺色／深色」是模擬作業系統偏好，只在選「跟隨系統」時有作用。
  9. 會員登入：只在 navigation.ts 標了 requiresAuth 的項目（含子路徑）出現，取代原本寫死的 /data/etf 判斷（YieldMax 不再誤顯示），放在色彩模式左邊。未登入是「G 登入」按鈕（手機只留 G）；登入後換成頭像，點開有帳號資訊、我的最愛 ETF、登出。可在「ETF 頁（會員）」直接點登入／登出測試。
